# Parking Lot Requirements

## Functional Requirements

### Vehicle Operations
- Park a vehicle
- Remove a vehicle
- Generate parking ticket
- Calculate parking charges

### Vehicle Types
- Motorcycle
- Car
- Truck

### Parking Spot Types
- Motorcycle Spot
- Compact Spot
- Large Spot

### Parking Lot
- Multiple Floors
- Multiple Entry Gates
- Multiple Exit Gates

### Parking Allocation
- Allocate nearest available spot
- Mark spot occupied
- Free spot on exit

### Ticket
- Ticket Number
- Entry Time
- Exit Time
- Parking Spot
- Vehicle Information

### Pricing
- Hourly pricing
- Different pricing for different vehicle types








- ## Non Functional Requirements

- Extensible
- Maintainable
- Scalable
- Thread-safe
- High Cohesion
- Low Coupling
