# 🚗 Parking Lot LLD

A production-quality Java implementation of the classic **Parking Lot Low-Level Design (LLD)** problem. This project focuses on writing clean, extensible, and maintainable object-oriented code by applying **SOLID principles**, **design patterns**, and **clean architecture** with **extensible and maintainable code**.

## 📌 Project Objective

The goal of this project is to design a scalable Parking Lot system capable of handling different vehicle types, parking spot allocation, ticket generation, pricing, and vehicle exit while following industry-standard software design practices.

---

## 🛠️ Tech Stack

- Java 21
- Maven
- IntelliJ IDEA
- JUnit 5 (Planned)

---

## 🎯 Features

- Support for multiple parking floors
- Multiple parking spot types
- Vehicle entry and exit
- Automatic parking spot allocation
- Parking ticket generation
- Parking fee calculation
- Extensible pricing strategies
- Clean object-oriented architecture
